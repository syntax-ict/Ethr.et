# A-Z acceptance review, 2026-11-03

A pre-launch review of ETHR from sign-up to payslip, journey by journey (A to I), run on a
fresh worktree off `main` at `aea7186e3` against a scratch MariaDB database (`ethr_az`).
It builds on the audits memory records as closed; it does not repeat them.

**How to read this register.** Each finding has an ID, the journey it belongs to, a severity
and the PR that fixes it. Severity: **S1** data loss, a security or cross-tenant failure, or
an organisation locked out; **S2** a wrong figure, a wrong decision recorded, or a control
that does not hold; **S3** a defect with a workaround or a narrow audience; **S4** cosmetic or
hardening. An UPGRADE entry is not a defect: it is a gap a demanding HR manager would notice,
with the proposed behaviour, effort and value. Upgrades marked *proposal* wait for the owner.

The repository is public, so security findings are described by behaviour only.

## Method

Each journey was traced in the code first, then every candidate defect was confirmed by a test
written before the fix: the test fails on `main` and passes on the fix branch, and the PR says
so. Figures in payroll findings are worked by hand, not taken from the engine. A finding that
could not be confirmed is not listed.

Environment: worktree `F:\ethr-wt-az` (off `origin/main`), PHP 8.3.36 and MariaDB 10.4 from
XAMPP, scratch database `ethr_az` (every migration run with `migrate:fresh`), mail to the log
driver, queues drained by hand. Production was not touched.

### Independent recomputation

25 employees, October 2026: every band edge (2,000.00, 2,000.01, 14,000.00, 14,000.01),
unpaid leave, hires on the 13th and the 25th, a leaver, normal, night, rest-day and holiday
overtime, loans (one a final instalment), cost sharing (one capped by what is owed), a
foreign national, and one employee with all of it. Seeded through the models, run through
the engine, approved, voided and reprocessed; recomputed by a separate script from the
statutory rules alone. With #554: **zero differences to the cent** in basic, gross, tax,
both pensions, deductions and net; run totals equal the entries; loan and cost-sharing
balances move on approval and return exactly on void. On `main`: two payslips differ, both
overtime on a reduced basic (F-01). Engine time for 25 employees: 1.3 to 1.5 s.

Outputs tied to the run: payslip PDFs in English and Amharic (Ethiopian calendar), the bank
file total, the register totals, the income tax schedule total, and the pension schedule (24
rows, the exempt foreign national left out). The journal did not tie (F-03).

Recomputed by hand for #554: C1 (777,777 hired on the 13th of June, two hours) overtime
132.58, gross 4,799.24, tax 459.85, net 4,012.72; C2 (912,345, a day and a half unpaid,
